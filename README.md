# 도어락 연습

집 도어락과 같은 방식으로 비밀번호 누르기를 연습하는 한 페이지짜리 웹앱입니다.
설치할 것 없이 브라우저에서 바로 열립니다.

## 열기

- https://metear0411-cyber.github.io/doorlock/

태블릿·휴대폰 크롬에서 열고 메뉴의 "홈 화면에 추가"를 누르면 앱처럼 전체 화면으로 실행됩니다.

## 쓰는 법

- 화면을 한 번 눌러 도어락을 깨우고, 번호를 순서대로 누릅니다.
- `*`이나 `#`은 지금까지 누른 번호를 지우는 키입니다.
- 오른쪽 위 톱니바퀴를 1초 조금 넘게 꾹 누르면 설정이 열립니다. 잘 안 되면 톱니바퀴를 빠르게 다섯 번 두드려도 열립니다.
  - 비밀번호(4~8자리), 깨우기 터치 여부, 번호 다음에 마지막으로 누르는 키를 실제 도어락과 똑같이 맞출 수 있습니다.
  - 마지막 키는 기본이 "없음"입니다. 번호 4자리를 다 누르면 바로 열립니다. 집 도어락이 `#`이나 `*`을 눌러야 하는 방식이면 설정에서 골라 주세요.
  - 힌트 단계는 3단계(다음 키를 밝게 + 음성)에서 0단계(실제 도어락과 동일)까지 있고, 자동으로 두면 성공이 쌓일 때마다 조금씩 줄어듭니다.
  - 소리·진동·음성 안내를 켜고 끌 수 있습니다.
- 연습 기록과 다음 연습 권장 시각도 설정 창에서 볼 수 있습니다.

## 저장되는 것

설정과 연습 기록은 그 기기의 브라우저 안(localStorage)에만 남습니다.
서버로 보내지 않으니 기기를 바꾸면 기록도 새로 시작합니다.
